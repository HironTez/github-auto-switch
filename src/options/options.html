GitHub Auto Switch

GitHub Auto Switch needs access to github.com to switch accounts.

Accounts

Open github.com once with each of your accounts. If you already use GitHub’s Switch account menu, switching to each account once is enough; otherwise add them with Add account in the same menu. The extension remembers every account a GitHub page is opened with and lists it here.

    No accounts yet. Open github.com signed in to one of your accounts.

    Which account opens a page

    Checked from top to bottom; the first match wins. Patterns ignore case, and * matches any part of a name, for example acme/*-infra.

    1. Repository rules

    2. Owner rules (organizations and users)

    3. github.com/account/… opens with that account.

    Activity log

    For troubleshooting: records what the extension sees and does on github.com (page addresses, which account each page showed, switches and their timing). It stays in this browser. Turn it off when you are done. 

    
      
    

      
    
        
    Good to know
    
        
      
          
    • 
            A browser has one signed-in GitHub account at a time, and only the GitHub tab in front
            switches it. Switching to a tab puts back the account its page was opened with, without
            reloading. The tab reloads instead if its page loaded, or sent updates, with another account
            while it was in the background.
          
      • 
          
    • Sign-in pages and account settings never trigger a switch.
      • 
          
    • 
            Signing out of an account on GitHub ends its saved sign-in too. Sign in again and the extension
            picks it up.
          
      • 
          
    • Saved sign-ins stay in this browser profile and are never synced or sent anywhere.
